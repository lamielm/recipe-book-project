# Recipe Book Project

- The point of the recipe book app is to receive recipes from a user, and allow them to store them and reference them.

## Features

- Display recipes
  - I'd like to choose from different meal categories like Breakfast, Lunch, Dinner, Snack, Dessert.
- Allow user to input a recipe of their choice
  - Have a few radio buttons that allow user to choose category, spicy?, more depending on growth of project...
